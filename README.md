# Job Monitor for macOS

一个放在 Mac 桌面上的职位提醒小工具。

打开后，桌面会出现一个 **M 图标**。点击它可以查看职位提醒，也可以添加你想关注的公司和岗位。

## 先说明：这是测试版

当前版本主要完成了桌面组件和设置页面，包括：

- 添加和管理公司
- 保存公司的招聘网址
- 选择 Product、AI/ML 等岗位方向
- 查看职位提醒
- 标记已经查看过的职位
- 在有新消息时显示红点
- 自动移除 14 天以前的提醒

但是，当前下载版还不能自己在后台访问招聘网站。

也就是说：普通用户下载后可以使用界面和配置功能，但 App 暂时不会自动在每天 09:30、18:30 搜索新岗位。这个功能会在后续版本加入。

## 下载安装

1. 打开 [Releases 下载页面](https://github.com/mengyi11/job-monitor-macos/releases)。
2. 下载最新的 `.dmg` 文件。
3. 双击打开下载的文件。
4. 将 **Job Monitor** 拖入“应用程序”文件夹。
5. 打开 Job Monitor。

如果 macOS 提示无法验证开发者：

1. 在 Finder 中找到 Job Monitor。
2. 右键点击 App。
3. 选择“打开”。
4. 在弹出的窗口中再次选择“打开”。

出现这个提示是因为测试版还没有经过 Apple 正式签名和公证。

## 怎么使用

### 1. 打开组件

启动 App 后，桌面左上角会出现一个 M 图标。

- 点击一次：展开职位提醒
- 再点击一次：收起提醒，只保留 M 图标
- 拖动图标：调整它在桌面上的位置

### 2. 添加公司

1. 点击 M 图标。
2. 点击“监控公司”或设置按钮。
3. 粘贴公司的官方招聘网址。
4. 确认自动识别的公司名称，也可以手动修改。
5. 选择一个或多个岗位方向。
6. 点击“保存配置”。

只有点击“保存配置”后，公司才会出现在监控列表中。

### 3. 查看职位

有新提醒时，M 图标会显示红点。

点击“查看”会打开对应的职位网页。打开后按钮会变成灰色的“已查看”，但仍然可以再次点击。

## 个人数据保存在哪里

所有配置和提醒记录都保存在你的 Mac 本地：

```text
~/Library/Application Support/JobMonitor/
```

下载包中不会包含开发者本人的：

- 公司配置
- 职位记录
- 浏览历史
- LinkedIn Cookie
- LinkedIn 登录信息

## LinkedIn 为什么比较特殊

LinkedIn 的职位页面经常需要登录，并且内容会根据账号和 Cookie 动态显示。

Job Monitor 不会读取或复制你在 Chrome 中的 LinkedIn 登录状态。后续如果加入 LinkedIn 自动检查，会提供单独、明确的登录和权限说明。

## 常见问题

### 关闭提醒窗口后，M 图标还在吗？

在。提醒窗口收起后，桌面会保留 M 图标，点击即可重新展开。

### 必须一直展开提醒窗口吗？

不需要。只保留 M 图标即可。

### 现在会自动检查岗位吗？

下载版暂时不会。当前 Beta 仍需要外部程序完成检索，再把结果交给 App 展示。

### 为什么第一次打开会有安全提示？

因为测试版使用临时签名，还没有完成 Apple Developer ID 签名和公证。

### 会上传我的配置吗？

不会。配置和提醒历史默认只保存在本机。

## 开发和编译

主要代码位于：

- `work/MicronJobWidget.m`
- `work/Info.plist`

使用 macOS Command Line Tools 编译：

```bash
xcrun clang -fobjc-arc -framework Cocoa work/MicronJobWidget.m \
  -o "Job Monitor.app/Contents/MacOS/MicronJobWidget"
```
